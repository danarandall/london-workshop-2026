# Round 1 Brief — Paste Verbatim

Do not add the word "accessible" anywhere. Do not add ARIA. Do not mention WCAG. Build what is asked, nothing more.

---

Build a retail banking dashboard as a single page web app.

Show one current account and one savings pot for a customer named Sam Okafor.

The account summary shows the current balance, the sort code, and the last four digits of the account number.

Show the last twenty transactions in a list. Each row shows merchant, date, amount, and status.

Add a primary action to move money from the current account to a saved payee. The user picks the payee, types the amount, and confirms.

Show a failure state if the payment cannot be processed.

Use the data in the three JSON files in project knowledge. Keep the design calm and modern.
