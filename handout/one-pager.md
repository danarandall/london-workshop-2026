## Round 1 rules

1. Paste `round-1-brief.md` verbatim
2. Do not add "accessible", ARIA, or WCAG
3. Ship what the tool gives you
4. Run the QA script. Note the score.

## Round 2 rules

1. Install ACCESSIBILITY-CORE.md from the toolkit into project knowledge
2. Start a fresh project
3. Paste `round-2-brief.md`
4. Paste `plain-language-strings.md` into project knowledge
5. Run the same QA script. Note the delta.

## The point

The gap between the two scores is what a rules file plus a plain-language brief buys you, without writing a line of code.
